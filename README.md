# Solar System Kids Explorer

An interactive, 3D web application designed to teach kids about the Solar System!

## Features
- **3D Solar System**: Interactive animated sun, planets, and realistic starfield using `Three.js` and `React Three Fiber`.
- **Planet Explorer**: Select any planet to view its 3D model up close and read interesting facts about its size, distance, and atmosphere.
- **Space Chat**: A simulated AI chat interface allowing kids to ask questions about space.
- **Beautiful UI**: Glassmorphism design system tailored for a dark space theme.

## Prerequisites
To run this application, you must have **Node.js** and **npm** installed on your system.

If you don't have Node.js installed, download it from [nodejs.org](https://nodejs.org/).

## How to Run
1. Open your terminal or command prompt.
2. Navigate to the project folder (`c:\antidemo`).
3. Install the required dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open your browser and navigate to the local URL provided by Vite (usually `http://localhost:5173`).

Enjoy exploring the universe!
